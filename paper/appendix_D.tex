\chapter{Performance Audit Results}
\label{app:performance-audit-results}

This appendix presents the detailed Lighthouse performance audit results used to evaluate the IRIS web application. The audit recorded the route group, route path, device mode, final loaded path, validity of the test, redirect status, Lighthouse performance score, First Contentful Paint (FCP), Largest Contentful Paint (LCP), Total Blocking Time (TBT), Cumulative Layout Shift (CLS), and Speed Index (SI).

The \texttt{/error-404} route was excluded from the main performance interpretation because it redirected to the home page during testing. Since Lighthouse evaluated the redirected home page instead of the intended error page, the result was not treated as a valid 404 performance result.
