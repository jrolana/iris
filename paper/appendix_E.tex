Sensitive tokens, credentials, and raw response bodies were excluded from this documentation.

\section*{Notes for Interpretation}

\begin{itemize}
    \item \textit{Passed} means the observed response matched the expected security behavior based on HTTP status and simple response inspection.
    \item \textit{Needs Review} does not automatically mean that the system is vulnerable. It means that the raw evidence should be manually inspected to confirm that no unauthorized data was returned.
    \item Some page-route tests used token/header-based requests, while the actual application uses browser-based cookie authentication. For this reason, some authenticated page-route tests may require manual review even when browser-based access control works correctly.
    \item \textit{Skipped} means the test was not executed because additional endpoint configuration or staging-safe settings were required.
    \item Sensitive tokens, credentials, environment variables, and raw private response bodies should not be included in the paper.
\end{itemize}
