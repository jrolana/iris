The web page shown in Figure \figref{fig:applicant_appview} shows the perspective of a technology generator when they want to view more details about a specific IP right application. It shows the current stage of the application, as well as the list of all status changes of the IP right application with timestamp (highlighting the latest status). The technology generator only has view privileges of the attachments and list of co-applicants on the IP right application.

For the TTBDO admin's side, it is shown in Figure \figref{fig:admin_appview} that it also shows the same IP right application details as the technology generators view. However, it can be seen that there are buttons that allow create, remove, update, delete (CRUD) operations on the list of attachments and inventors. Moreover, the TTBDO admin is responsible for updating the status of an application as well as moving the application to another stage of the application process.
