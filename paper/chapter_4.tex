\chapter{System Prototype}
This chapter presents the IRIS system prototype, highlighting its key features and user interfaces. The prototype demonstrates functionalities such as authentication with role-based access control, application creation and management, notifications, dashboards, and access to IP application documents and guides. Screenshots illustrate the perspectives of Technology Generators, TTBDO admins, UP officials, and Guests, showing both view-only and full management capabilities, as well as the workflow of starting and tracking IP right applications.

\section{Authentication}
The IRIS system prototype can handle authentication for registered accounts. It has protected routing for role-based access control (RBAC). It facilitates sign-in with Google emails that should already be registered with Supabase.

\section{Specific Application View}
Both the technology generators and the TTBDO admin can view a list of applications. They can also interact with a specific application, which prompts them to a different web page that shows specific details about that application.

\subsubsection{Technology Generator View}
The web page shown in \figref{fig:applicant_appview} shows the perspective of a technology generator when they want to view more details about a specific IP right application. It shows the current stage of the application, as well as the list of all status changes of the IP right application with timestamp (highlighting the latest status). The technology generator only has view privileges of the attachments and list of co-applicants on the IP right application.

\section{Notification}
IRIS has a notification component that is only available for technology generators and the TTBDO admin. Whenever there are changes (e.g., attachments submitted, status updated, title updated, application stage moved etc.) on an application, the technology generator is notified. Moreover, the TTBDO can also see notification whenever there are new applications started, or they have been contacted by a technology generator. \figref{fig:notification} shows the panel that pops up whenever the authenticated users interact with the bell icon on the top bar. The panel shows the notifications that are chronologically ordered to show the latest notification at the top.

\section{Application Registry}
The Application Registry provides users with a quick overview of all IPs, allowing them to easily browse and reference relevant information. The registry is largely uniform across user roles, with some exceptions. Technology Generators do not require a separate registry since their applications are already accessible from the dashboard (\figref{fig:dashboard_techgen_table}). Admins have full control to manage IP rights, as illustrated in \figref{fig:registry_admin}, while UP officials and Guests have read-only access to view IP information (\figref{fig:registry_guest}). Guests have an additional constraint: they can request access to view more details about a specific IP, a feature planned but not yet implemented in the current prototype.

\section{Application Documents}
The Application Documents page provides a centralized location for users to view all forms and related documents associated with the IP application process. Both Guests and Technology Generators can access the page and initiate applications using the call-to-action buttons. However, only Technology Generators can track their latest submissions, as illustrated in \figref{fig:documents_techgen}. Clicking the button redirects Technology Generators to a dedicated application page that displays detailed information about their specific IP right applications (\figref{fig:applicant_appview}), enabling them to monitor progress, while Guests are primarily guided to apply.
